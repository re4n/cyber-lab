# cyber-lab

Hands-on cybersecurity study repo: notes from a structured study track, plus a physical networking and Linux homelab.

## Structure

```
cyber-lab/
├── notes/          study notes (commands and lessons learned)
├── homelab/        isolated networking and Linux lab
└── bandit-notes/   bandit notes levels
```

## Studies
I'm studying cybersecurity, and the notes from each study task are committed in notes/.

Notes contain commands and lessons only: no passwords, tokens or personal data.

## Homelab

An isolated physical lab (no internet) to practice networking (VLANs, routing, packet capture) and Linux, built around a Cisco SG250 switch and a Linux server. Status: structure phase, nothing built yet.

Details: [`homelab/homelab-sheet.md`](homelab/homelab-sheet.md)
